# JSKeyboard
#
# iOS 键盘扩展应用 - JavaScript 快捷输入工具
#
# 功能：
#   界面1：自定义多个目录及多条文字，长按可编辑/删除
#   界面2：剪贴板历史记录，点击即可插入文本
#   界面3：JavaScript 函数快捷输出，支持有参/无参两种模式
#   界面4：设置（字体大小、音效、震动、自动保存等）
#
# 构建方法：
#   1. 确保已安装 Xcode 15+ 和 iOS SDK
#   2. 打开 Xcode，选择 File > Open > 选择 JSKeyboard.xcodeproj
#   3. 在 Xcode 中设置 Team / Bundle ID
#   4. 将 iOS 设备连接至 Mac
#   5. 先 Build & Run 主应用 JSKeyboard
#   6. 在设备上：设置 > 通用 > 键盘 > 添加新键盘 > JSKeyboard
#   7. 返回任意 App 即可使用自定义键盘
